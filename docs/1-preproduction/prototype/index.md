# 簡易模型試玩

**狀態：尚未開始**

在寫程式之前，先用紙本或簡易工具模擬一局，驗證玩家會不會笑、會不會吵。這是 [階段 1 檢核關卡](../gate) 的第二個條件。

## 試玩形式（建議）

- **紙上原型**：一人扮演爺爺加律師（主持人），四人扮演子孫
- **道具卡**：28 件道具做成卡片，正面是名稱，背面是數值；分房間洗成牌堆
- **爺爺性格卡**：主持人抽一張，不公開
- **計時**：探索 30 秒（抽卡）、病房 20 秒（決定送禮或跳過）
- **反應**：主持人照 [送禮反應](../content/items/reactions) 的台詞念出爺爺反應與律師登記

## 要驗證的問題

- 玩家每天做決定時，有沒有在猶豫？
- 玩家之間有沒有互動、爭執或互相指責？
- 哪一刻全場大笑？
- 第幾天開始覺得重複？
- 最終審判時有沒有懸念？
