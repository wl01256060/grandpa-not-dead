# 技術選型

## 已確定

- **引擎**：Unity 2D
- **平台**：Steam（PC）
- **大廳與邀請**：Steam Lobby 與好友邀請
- **權威架構**：房主權威。只有房主能修改 HP、心情、分數與背包；客戶端只送出請求
- **資料驅動**：道具、性格、任務、事件都存成 ScriptableObject 或 JSON，可調數值集中在一份設定檔
- **私密資料**：背包、秘密任務、搜索結果由房主只傳給該玩家，不能只靠前端隱藏

## 待決定

::: warning 需要在製作開始前決定
規格書 v0.2 要求在 W1 內完成選型。

- [ ] **多人同步框架**：選定後評估 RPC、可靠同步、斷線重連的實作成本
- [ ] **WASD 自由移動的同步方式**：規格書原本是場景切換加點擊，改成自由移動後，位置同步和延遲處理的成本要重新評估
- [ ] **房主斷線處理**：MVP 是否維持「直接結束對局」

## 注意事項

- Steam 的 Lobby 和 Relay 是平台能力，不等於完整的遊戲同步框架。RPC、狀態同步、房主權威邏輯和斷線處理仍需自行開發。
- 每個玩家動作附 actionId，重複封包直接回傳既有結果，避免重複加分。
