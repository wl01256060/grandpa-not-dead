# 美術方向

## 整體風格

- 俯視 3/4 視角像素風，可以同時看到後牆與家具正面
- 暖色復古調色：橘、棕、橄欖綠、米白，深色描邊
- 參考素材：[Top-Down Retro Interior](https://penzilla.itch.io/top-down-retro-interior)
- 遊戲畫面固定視角，不做鏡頭切換；情緒靠對話框頭像、角色頭上的情緒圖示與數值飄字表現

## 場景

- 病房不是醫院，而是豪宅裡的臥室，加上病床和點滴架
- 後牆擺一座落地鐘，滴答聲當作七天倒數的隱喻
- 其他房間：廚房、書房、客廳、儲藏室，使用素材中的書櫃、沙發、地毯、壁爐等家具

## 角色外觀

每人一個專屬輪廓加一件招牌道具，縮成小頭像或剪影也分得出來。

### 王家豪｜長子・60 歲・特助

- **輪廓**：永遠微微彎腰，大約 15 度，像隨時準備鞠躬
- **髮型與表情**：旁分油頭梳得服貼，鬢角全白。感覺畏畏縮縮
- **穿著**：灰色西裝，領帶打得一絲不苟。戴司機的白手套
- **招牌道具**：一手拿爸爸的保溫杯，一手拿手帕擦汗
- **暗示陰暗面的細節**：西裝內袋露出一角黑色小筆記本

### 王美玲｜長女・57 歲・國中老師

- **輪廓**：抬頭挺胸，手臂夾著一本厚資料夾
- **髮型與表情**：短燙捲髮，嘴角往下
- **穿著**：多口袋背心，每個口袋都插著紅筆和螢光筆，腳上是健走鞋
- **招牌道具**：兩副眼鏡，一副推在頭上，一副用鍊子掛在胸前。資料夾封面寫著「爸 支出明細」
- **細節**：手腕戴計算機手錶，斜背包塞滿收據

### 王琪琪｜孫女・26 歲・網紅

- **輪廓**：背後背著一圈環形補光燈，像頭頂掛著光環
- **髮型與表情**：粉紫漸層長捲髮。永遠擺出對鏡頭的 45 度角微笑
- **穿著**：粉色系穿搭，全身貼滿虛構品牌的業配小標籤
- **招牌道具**：自拍棒舉著手機，領口夾一支麥克風
- **誇張細節**：只化了面對鏡頭的那半邊妝

### 王冠宇｜孫子・29 歲・創業家

- **輪廓**：脖子上掛著五六條新創活動的識別證，走路時嘩啦作響
- **髮型與表情**：刻意弄亂的捲髮。永遠比著「十倍」的手勢，一臉自信
- **穿著**：連帽衫外面套西裝外套，腳上是限量球鞋，但鞋底已經開口笑
- **招牌道具**：平板電腦顯示一路往上的成長曲線，但螢幕裂了
- **細節**：無線耳機只戴一邊，另一邊說「在等投資人的電話」

### 王安然｜孫女・24 歲・禮儀公司業務

- **輪廓**：雙手交握放在身前，站姿端正，跟家豪的彎腰形成對比
- **髮型與表情**：整齊的低馬尾。永遠平靜的職業微笑
- **穿著**：全黑套裝，胸前別一朵白色小花，腳上是走路沒聲音的黑色平底鞋
- **招牌道具**：脖子掛一條捲尺，手上一疊「頭七套餐」DM
- **細節**：名牌寫著「生前契約專員」

### 角色主色

家豪灰棕、美玲卡其、琪琪偏暖的粉、冠宇海軍藍、安然黑白。都從素材色系中挑選。

## 角色 sprite

- 大約 1.5 格高的 Q 版比例，配合家具比例
- 招牌輪廓在小 sprite 上也要看得出來

## UI

- **對話框**：米白底、深棕粗邊框，左側為說話者的像素頭像，逐字打出並配打字音效
- **HP 條**：橄欖綠，扣血時變磚紅色
- **數值飄字**：加分用橄欖綠、扣分用磚紅色，往上飄 1 秒後消失
- **情緒圖示**：！、？、💢、…，深棕描邊、米白底的小泡泡

## 頭像表情需求

| 角色 | 需要的表情 |
| --- | --- |
| 爺爺 | 一般、開心、生氣、驚嚇、無言、死亡 |
| 子孫 | 每人 1 到 2 張 |
| 律師 | 1 張（面無表情） |
