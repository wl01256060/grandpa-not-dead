## 整體風格

- 俯視 3/4 視角像素風，可以同時看到後牆與家具正面
- 暖色復古調色：橘、棕、橄欖綠、米白，深色描邊
- 參考素材：[Top-Down Retro Interior](https://penzilla.itch.io/top-down-retro-interior)
- 遊戲畫面固定視角，不做鏡頭切換；情緒靠對話框頭像、角色頭上的情緒圖示與數值飄字表現

## 場景

- 病房不是醫院，而是豪宅裡的臥室，加上病床和點滴架
- 後牆擺一座落地鐘，滴答聲當作七天倒數的隱喻
- 其他房間：廚房、書房、客廳、儲藏室，使用素材中的書櫃、沙發、地毯、壁爐等家具

## 角色外觀

各角色的輪廓、穿著、招牌道具與主色，寫在 [角色設定](../world/characters#繼承人) 各繼承人的「外觀」段落。

## 角色 sprite

- 大約 1.5 格高的 Q 版比例，配合家具比例
- 招牌輪廓在小 sprite 上也要看得出來

## UI

- **對話框**：米白底、深棕粗邊框，左側為說話者的像素頭像，逐字打出並配打字音效
- **HP 條**：橄欖綠，扣血時變磚紅色
- **數值飄字**：加分用橄欖綠、扣分用磚紅色，往上飄 1 秒後消失
- **情緒圖示**：！、？、💢、…，深棕描邊、米白底的小泡泡

## 頭像表情需求

| 角色 | 需要的表情 |
| --- | --- |
| 爺爺 | 一般、開心、生氣、驚嚇、無言、死亡 |
| 子孫 | 每人 1 到 2 張 |
| 律師 | 1 張（面無表情） |
