# 爺爺反應與台詞

來源：設定集 v0.3（王大富版）第 3、7 節。

送出道具後，爺爺先說**第一句**（依性格與道具）；孝心結果小於 0 時再加一句**嘲諷**；律師最後補一句**登記**。每句 1 到 2 行。

::: warning 待確認
設定集寫律師只在「送出孝心為負或明顯離譜的道具」時才登記；[遊戲機制規格](../mechanics/#送禮結算)寫的是每次送禮都登記。需要確認以哪個為準。
:::

## 三種性格的台詞

性格的喜惡分類與數值見 [角色設定](../world/characters#三種性格)。

| 性格 | 開場獨白 | 招牌台詞 |
| --- | --- | --- |
| 暴躁 | 「你們站著幹嘛？我還沒死！」 | 「這種東西也拿來給我？」、「拿到我眼前再說！」、「我還沒死，你們先別急。」 |
| 愛面子 | 「送禮要有格調。我有錢，但我不亂花——你們有帶格調來嗎？」 | 「哈，還算有點眼光。」、「這種貴氣才配得上我。」、「便宜貨拿回去，留著自己用。」 |
| 腹黑 | 「你們都以為我不知道吧。」 | 「嗯……你來送這個，是想讓我想起什麼呢？」、「我記得你昨天不是這樣說的。」、「收下了，我很感動。（對律師）記下來。」 |

愛面子是規格書 v0.2「敗家」的新名稱：王大富設定上是節儉的人，改成愛面子比較合理。

## 嘲諷池

單次孝心結果小於 0 時，從該性格的池中隨機抽一句。

| 性格 | 嘲諷 |
| --- | --- |
| 暴躁 | 「你是來孝順的，還是來送行的？」、「拿回去！這東西連垃圾桶都嫌！」、「我蓋了六十年房子，沒見過你這麼會拆的。」、「你這份禮物，律師剛剛抄了兩頁。」、「我當年做生意都沒你們這麼不要臉。」、「下次先問自己：這東西，我自己會吃嗎？」 |
| 愛面子 | 「品味？你把它放哪兒了？」、「這種東西，連垃圾都不願意認識它。」、「請告訴我，你是因為窮，還是因為壞？」、「送禮要送得體面，你送的是一場事故。」、「律師，記下來：這位的品味，是我遺產以外的損失。」、「我的眼睛有點痛，是因為你。」 |
| 腹黑 | 「喔，你送這個……是想讓我想起什麼嗎？」、「很有創意。我會記著，記得比遺囑還久。」、「你這份禮，我收下了。只是還沒決定拿來做什麼。」、「謝謝你。我真的很感動。（對律師）記下來。」、「你以為我不知道這是誰教你的嗎？」、「這份心意，我會在最後一天回禮。」 |

## 連環嘲諷

累犯加碼，取代上面的隨機嘲諷。每種每局每人最多觸發 2 次。

| 觸發條件 | 暴躁 | 愛面子 | 腹黑 |
| --- | --- | --- | --- |
| 連續第 2 次送出負分禮物 | 「又？你是不是故意的？」 | 「同一種品味，兩次。太穩定了。」 | 「第二次了。我開始期待第三次。」 |
| 連續第 3 次 | 「你到底有沒有在看我的表情！」 | 「律師，請把這位的名字寫大一點。」 | 「我開始懷疑，你是來繼承的，還是來搞笑的。」 |
| 送出與前一天相同的道具 | 「這個我昨天收過了！你是不是沒東西可送？」 | 「重複的禮物，就像重複的謊話，很沒品。」 | 「喔，又是這個。你很喜歡它，還是你只找得到它？」 |
| 排名墊底又送負分 | 「都最後一名了，還敢亂來？」 | 「墊底的人，連失敗都不夠優雅。」 | 「墊底的人最安靜，也最危險。可惜你只是安靜。」 |
| 同一天第二次送出厭惡分類 | 「我剛剛才說過！」 | 「我才剛說過廉價。你的記憶比你的禮物還廉價。」 | 「你聽見了。只是你不在乎。」 |
