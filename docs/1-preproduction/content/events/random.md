# 事件｜隨機事件

每局抽到的事件不同，是讓每一局有變化的主要來源。固定劇情見 [開場與固定事件](./fixed)。

## 抽事件的規則

- 第 2 到 6 天，每天 60% 機率抽一個事件，一局最多 3 個（[遊戲機制規格](../../mechanics/#事件)）
- 第 1 天和第 7 天不抽（設定集 v0.3）

## 事件清單

| 事件 | 效果 | 狀態 |
| --- | --- | --- |
| 私生子登場 | 所有玩家當日孝心 −5 | 規格書 v0.2 |
| 律師查房 | 規則需配合取消揭發重新設計 | 待改 |
| 爺爺清醒 | 當天首件正面禮物基礎孝心 ×2 | 規格書 v0.2 |
| 遺囑遺失 | 書房搜到特殊道具的機率 +15 個百分點 | 規格書 v0.2 |
| 前女友來訪 | 當天喜惡加成翻轉 | 規格書 v0.2 |
| 爺爺發飆 | 當天所有送禮孝心 −10 | 規格書 v0.2 |
| 假死 | 爺爺倒下後突然醒來；玩家反應待設計 | 已決定加入 |
| 二姑婆查戶口、大伯借錢、葬儀社推銷 | 糟糕親戚 NPC 事件 | 提案 |

## 假死

爺爺倒下，所有人以為他死了，接著他突然醒來。

- 參考台詞：爺爺倒下，畫面傳出歡呼聲，爺爺突然睜眼：「剛剛是誰在歡呼？」
- 待設計：觸發機率、玩家在倒下期間可以做的反應
