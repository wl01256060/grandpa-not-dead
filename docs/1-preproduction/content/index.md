## 送禮對話（demo 版）

格式：子孫說要送什麼 → 爺爺反應（表情）→ 律師登記 → 數值。子孫的台詞故意平淡，笑點落在爺爺的反應和律師的補刀。

### 感謝狀｜王琪琪｜很假，但有效

- 琪琪：「爺爺，送您粉絲投票選出來的人氣獎，看鏡頭～。」
- 爺爺【開心】：「『頒給世界上最偉大的爺爺』，說得好！裱框，掛大廳。」
- 律師：「登記：人氣獎狀一張。製作者與受獎者，皆知其為假。」
- 數值：孝心 +25

### 炸雞全家餐｜王家豪｜爺爺開心，但扣 HP

- 家豪：「爸，您最愛的炸雞。全家餐，您一個人吃。」
- 爺爺【開心】：「這才叫孝順！醫生都不讓我吃！」
- 律師：「登記：醫囑已違反，家屬所為。」
- 數值：孝心 +20、HP −25

### 輪播相框｜王美玲｜反轉，爺爺生氣

- 美玲：「爸爸，送您的輪播相框，裡面有我們的全家福。」
- 爺爺【開心】：「哇，這是最新科技！」
- 爺爺【生氣】：「……為什麼有我的黑白照？」
- 律師：「登記：輪播相框一台，遺照已提前試播。」
- 數值：孝心 −35

## 寫對話的方法

每件禮物先填一張小卡：

1. 誰送？
2. 他的私心是什麼？
3. 禮物的賣點是什麼？
4. 戳到爺爺哪個按鈕？（錢、動機、死）
5. 最後一句誰贏？（永遠是爺爺）

常用技巧：

- **把禮物的廣告詞套到死亡或遺產上**：例如鞋子「走遠路不會累」→ 爺爺：「我要走去哪？」
- **用角色的職業術語講親情**：美玲講請款與回饋、冠宇講 A 輪與估值、琪琪講業配與按讚、安然講早鳥與尺寸
- **爺爺永遠反殺**：孫子想佔便宜，爺爺比他更摳、更黑
- **話說一半，後半句露餡**
- **從真實親戚身上取材**

檢查：念出來三句內有沒有笑點？遮住名字猜得出是誰說的嗎？爺爺的表情有沒有轉折？
