# 內容庫

- [送禮反應](./items/reactions)：每件道具在三種性格下的第一句、律師登記、嘲諷池、連環嘲諷
- <span class="chg">[陷害道具](./items/traps)：暗中登記、開獎才生效的小陷害、大陷害與防守道具（2026-11-20 新增）</span>
