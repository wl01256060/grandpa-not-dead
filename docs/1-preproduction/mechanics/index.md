# 遊戲機制規格

所有數值都是提案，待遊測調整。

<span class="chg">整體流程的圖解見 [遊戲流程圖](../flow)。</span>

<div class="chg-legend">2026-11-19～20 改動：<span class="chg">黃底</span> 是新增或修改，<del class="rm">紅色刪除線</del> 是移除。</div>

## 基本架構

- 4 人線上 Steam 派對遊戲，房主為權威端
- 一局 7 天，目標 8 到 10 分鐘
- 每位玩家從 [角色池](../world/characters#繼承人) 選一位角色，不能重複
- WASD 自由移動，俯視角像素風豪宅

## 每天的流程

| 階段 | 時間 | 玩家做什麼 |
| --- | --- | --- |
| 探索 | <del class="rm">30 秒</del> <span class="chg">50 秒</span> | 在豪宅裡移動、搜索、使用能力<span class="chg">；隨時可以走到病房送禮，見下方「送禮」</span> |
| <del class="rm">病房</del> | <del class="rm">20 秒</del> | <del class="rm">送禮或跳過，二選一，提交後不能改</del> |
| 結算 | 10 秒 | 看當天孝心變化、爺爺狀態、事件預告<span class="chg">；小陷害與秘密道具開獎；律師念當天的紀錄與章節旁白</span> |

<span class="chg">病房不再是獨立階段，所有人同時進入下一段的只剩「探索 → 結算」。一天的總時間維持 60 秒。</span>

<span class="chg">結算的順序：① 小陷害與秘密道具開獎 → ② 排行榜更新 → ③ 律師登記一件當天的禮物 → ④ 明天的事件預告。</span>

第七天結束時進入最終審判。爺爺在第七天之前 HP 歸零（提前死掉）時，立即進入最終審判，照常計算最終分數，最高分的玩家獲勝。

## 豪宅與搜索

- 五個房間：病房、廚房、書房、客廳、儲藏室
- 病房以外的房間是私人空間，別人看不到你在哪、搜到什麼
- 每個房間 2 個搜索點；按下搜索後有 2 秒進度條
- 每個搜索點冷卻 5 秒，每天最多成功搜索 3 次
- 背包容量 1 格，滿了要先送出或丟棄

## <span class="chg">送禮</span>

- <span class="chg">探索期間，玩家拿著道具走到病房、站到爺爺旁邊按 E 就能送出，不用等固定時段</span>
- <span class="chg">每人每天最多送 2 次。背包只有 1 格，送完才能再去找下一件</span>
- <span class="chg">取捨：手上這件中等的禮物要先送掉，還是賭之後找到更好的？先送的人也等於幫別人試出爺爺的喜好</span>
- <span class="chg">道具分成兩種，送出後的效果不同：</span>

| <span class="chg">種類</span> | <span class="chg">送出後</span> | <span class="chg">何時生效</span> |
| --- | --- | --- |
| <span class="chg">一般禮物（28 件）</span> | <span class="chg">排行榜馬上變動</span> | <span class="chg">立刻</span> |
| <span class="chg">陷害道具、角色秘密道具</span> | <span class="chg">排行榜不變，暗中登記；陷害道具要從名單選一名對象</span> | <span class="chg">開獎時，見 [陷害道具](../content/items/traps)</span> |

## <span class="chg">即時排行榜</span>

- <span class="chg">UI 上全程顯示四位玩家的孝心與名次，一般禮物送出後馬上更新</span>
- <span class="chg">排行榜只反映「已經生效」的分數。暗中登記的陷害道具要到開獎才會改變排行榜，所以第一名看起來很穩，不代表真的很穩</span>
- <span class="chg">設計意圖：一直看得到誰領先，刺激大家採取行動；陷害道具的開獎則保留不確定性。大家都會想打第一名，所以太早當第一名反而危險</span>

## <span class="chg">病房監視器與上方對話框</span>

- <span class="chg">**監視器**：UI 上固定有一個監視器圖示，任何時候都可以點開，看病房的即時畫面。開著時仍可以移動和搜索</span>
- <span class="chg">**監視器裡只有爺爺是清楚的**：進病房送禮的人一律顯示成同一個統一造型，看不出是誰</span>
- <span class="chg">**上方對話框**：沒開監視器時，畫面上方顯示爺爺正在說的話，不顯示是誰送的</span>
- <span class="chg">**作用**：一般禮物看排行榜就知道是誰送的；統一造型是為了讓**陷害道具的送出者保持匿名**。大家只看得到「有人交了一份東西，排行榜卻沒動」，知道有事要發生，但不知道是誰、對誰</span>
- <span class="chg">**送出陷害道具時爺爺說的話（提案）**：不透露內容的一句，例如暴躁「這是什麼？……先放著。」、愛面子「信封這麼寒酸。……放著吧。」、腹黑「收下了，我很感動。（對律師）記下來。」</span>

## 道具

- 一般道具共 28 件，分六類：照護、懷舊、奢侈、廉價、惡作劇、秘密
- 每件道具有孝心、HP、心情三種數值，見 [道具數值效果](../content/items/stats)
- 掉落比例：普通 70%、負面 25%、特殊 5%
- 部分惡作劇道具會偽裝成正常禮物，爺爺用了才揭曉
- <span class="chg">另有陷害道具與防守道具，每局隨機放 3 件，見 [陷害道具](../content/items/traps)</span>

## 送禮結算

```
個人孝心增量 = 道具基礎孝心 + 性格修正（+15 / 0 / −15）+ 角色能力 + 事件修正
```

- HP 和心情依道具增減，限制在 0 到 100
- 爺爺先說第一句反應；孝心為負時加一句嘲諷<del class="rm">；律師最後補一句登記</del>
- <span class="chg">律師不再每次送禮都登記，只在每天結算和最終審判出場，減少玩家要讀的台詞</span>
- <span class="chg">分數變化直接顯示在排行榜上，玩家不需要從台詞判斷分數</span>

## 爺爺

- HP 100、心情 50
- 三種性格每局抽一種，見 [爺爺](../world/characters#爺爺)

## 事件

- 第 2 到 6 天，每天 60% 機率抽一個事件，一局最多 3 個
- 假死是其中一種機率事件：爺爺倒下，所有人以為他死了，接著他突然醒來

## 角色能力、秘密任務與秘密道具

秘密任務為角色專屬，只有本人看得到，最終審判才公開。

<span class="chg">每個角色用不同的方式「衝第一」或「防陷害」：</span>

| <span class="chg">角色</span> | <span class="chg">風格</span> | <span class="chg">一句話</span> |
| --- | --- | --- |
| <span class="chg">琪琪</span> | <span class="chg">爆發得分</span> | <span class="chg">賭對了一口氣衝上第一，賭錯重摔</span> |
| <span class="chg">安然</span> | <span class="chg">穩定得分</span> | <span class="chg">最不會送錯禮，分數穩穩爬</span> |
| <span class="chg">美玲</span> | <span class="chg">防守</span> | <span class="chg">陷害道具的剋星，第一名會想跟她結盟</span> |
| <span class="chg">家豪</span> | <span class="chg">抗打</span> | <span class="chg">不怕當第一名，被打越多最後回本越多</span> |
| <span class="chg">冠宇</span> | <span class="chg">操控排行榜</span> | <span class="chg">跟第一名借分，對方掉名次、自己暫時升上去</span> |

### 王家豪｜長子

- <del class="rm">**能力「爸說得對」（被動）**：送出負分禮物時，孝心扣分減半</del>
- <span class="chg">**能力「忍到最後」（被動）**：被陷害時，效果減半（數值類效果減半；互換類效果改成只移動差距的一半）；每被陷害一次，最終審判 +10</span>
- **秘密任務「第十六本」**：七天內用惡作劇道具讓爺爺 HP 累計扣掉 40 以上 → +25
- **秘密道具「第十五本筆記」**：爺爺讀完：「……第一頁是我罵你的那天？」

### 王美玲｜長女

- **能力「Excel」（主動，每天 1 次）**：查看一名玩家的背包內容<del class="rm">與當天孝心增量</del><span class="chg">；如果裡面是陷害道具或秘密道具，可以直接沒收（丟棄）</span>
- **秘密任務「平分最公平」**：遊戲結束時自己是第一名，或跟第一名差距 ≤ 20 → +20
- **秘密道具「老爸欠款明細」**：爺爺：「我養你五十七年，有列進去嗎？」

### 王琪琪｜孫女

- **能力「開直播」（主動，一局 3 次）**：開直播那天，自己送禮的孝心增減 ×1.5<span class="chg">（扣分也 ×1.5）</span>
- **秘密任務「感人結局」**：第 7 天開直播，而且當天爺爺心情 ≥ 70 → +25
- **秘密道具「冠名合約」**：爺爺：「我的死，你抽幾成？」

### 王冠宇｜孫子

- **能力「A 輪投資」（主動，一局 2 次）**：向一名玩家借 10 孝心，三天後自動還 15；遊戲先結束就不用還<span class="chg">。借款馬上反映在排行榜上</span>
- **秘密任務「還沒翻身」**：遊戲結束時仍有未歸還的借款 → +20
- **秘密道具「爸爸的借據」**：爺爺：「父債子還，你帶錢來了嗎？」

### 王安然｜孫女

- **能力「職業病」**：被動看得到爺爺精確的 HP；主動每天 1 次偷看爺爺的一項喜好分類
- **秘密任務「早鳥方案」**：爺爺在第 7 天之前 HP 歸零 → +30
- **秘密道具「頭七套餐預購單」**：爺爺：「這麼早就幫我排好了？有沒有打折？」

### 秘密道具規則

- 只在該角色參戰時出現在豪宅裡，不佔 28 件一般道具的名額
- **別人送出**：等於當眾拆穿。該角色 −20，送出的人 +15
  - <span class="chg">送出時暗中登記，排行榜不變。當天結算時開獎：爺爺念出秘密道具的專屬台詞並點名被拆穿的角色，該角色 −20</span>
  - <span class="chg">送出者的 +15 到最終審判才加，否則排行榜一跳 15 分就知道是誰送的</span>
  - <span class="chg">送出者一律匿名，最終審判時律師才公開</span>
- **本人送出**：等於自首。不加不減，但爺爺有專屬台詞
- 取消揭發後，這是玩家之間互相陷害的主要方式<span class="chg">，另有 [陷害道具](../content/items/traps)</span>

## 最終審判

```
最終分數 = 七天累積孝心 + 秘密任務獎勵 + 秘密道具獎懲
```

<span class="chg">計算順序：① 大陷害開獎（改動七天累積孝心）→ ② 加上秘密道具送出者的 +15 與家豪「忍到最後」的獎勵 → ③ 秘密任務開獎 → ④ 宣布繼承人。</span>

- 爺爺提前死掉時，也照上面的公式計算，秘密任務與秘密道具的獎懲都算
- 同分時，先比正面送禮次數，再以固定隨機種子決勝
- 律師播報本局最荒謬的三筆紀錄，宣布繼承人
- <span class="chg">律師公開每一件陷害道具與秘密道具是誰送的、送給誰，當作最後的爆點</span>
