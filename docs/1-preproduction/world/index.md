# 世界觀

## 一句話

地產大亨王大富確診只剩七天，宣布遺產全部給最有孝心的人。各房的兒女和孫子連夜趕回豪宅，表面孝順、暗地爭產，四處翻找能討好爺爺的東西。

## 故事前提

- 王大富，85 歲，大富建設創辦人，綽號「地王」。從工地搬磚起家，做到建案、商辦、飯店和安養大樓。
- 他非常有錢，卻極度摳門、多疑、嘴壞。
- 他規定每一房派一個代表進病房，遺產給最孝順的那一房。有的兒女親自來，有的不能來、不敢來，就派小孩代打。
- 家族律師在病房門口登記每一件禮物，第七天宣讀遺囑。

## 角色

見 [角色設定](./characters)：

- [爺爺](./characters#爺爺)：被送禮的對象，也是全場最糟的親戚
- [繼承人](./characters#繼承人)：玩家從中選一位扮演
- [家族律師](./characters#家族律師)：紀錄者、最終審判主持

## 基調與尺度

- **黑色幽默與地獄梗，不走溫情路線**。目標是讓玩家想起自己遇過的糟糕親戚。
- **爺爺是全場最清醒的人**。玩家想佔便宜，爺爺永遠比他更狠，讓玩家有「被看穿」的快感。
- **笑死亡和貪婪，不笑病**。爺爺拿自己的死開玩笑效果最好；不嘲笑外貌、性別、族群、真實疾病與宗教政治。
- **不使用真實人物與真實品牌**。
- **每句台詞 1 到 2 行**，玩家才讀得完。

## 遊戲名稱的由來

爺爺被問到病情時，永遠只有一句話：「我還沒死！」這句話會出現在遊戲各處，也是 demo 影片的收尾。
